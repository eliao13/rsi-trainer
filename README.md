# Bear Trainer

Practise reading Bear's RSI setups: see the chart up to his entry, call the side and size, then replay the trade minute by minute against his alerts.

Live: https://eliao13.github.io/rsi-trainer/

## Develop

```bash
npm install
npm run dev      # local dev server
npm test         # unit tests (indicators, exits, message filter)
npm run build    # production build into dist/
```

Pushing to `main` runs the tests, builds, and publishes to GitHub Pages (`.github/workflows/deploy.yml`). Pages must be set to **Settings → Pages → Source: GitHub Actions**.

## Layout

- `src/App.tsx`: one round (guess → replay → done), saved progress, keyboard shortcuts
- `src/components/`: chart (canvas), action bar, timeline, results, history, charts dialog
- `src/lib/`: indicators, trade maths (auto-sell, Bear-style exit, lessons), message filter, storage, chart images
- `public/data/`: trades and 5-minute bars, generated by `build_data.py`
- `scripts/realdata.stats.test.ts`: how the divergence detector and swing stop behave on all trades (`STATS=1 npx vitest run realdata`)

## 1-minute chart

The replay can show 1-minute bars for timing exits. Export them on the machine with the raw Dukascopy files (the repo folder should sit next to `bear-backtest/` and the `bear-ideas_*.csv` files, or pass `--raw <folder>`): `python build_data.py --m1-only`. On Windows you may first need `pip install tzdata`. It writes `public/data/m1_<instrument>_<year>.js` (trade days, 8:30–16:00 ET) and `public/data/m1_index.js`. Commit and push those, and the **1 min** button appears for trades that have data.

Bear's chart screenshots are never published with the site. Users load them from their device or a private GitHub repo, and they're cached in the browser.
